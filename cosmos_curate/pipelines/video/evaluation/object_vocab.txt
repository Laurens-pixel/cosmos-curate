# Curated open-vocabulary object class list for the object-grounding / CHAIR metric.
#
# This is a FIXED, standard object vocabulary — like COCO-80 or LVIS in open-vocabulary
# detection evaluation. It is deliberately independent of the captions being evaluated (using
# caption-derived classes would be circular and would bias recall/CHAIR).
#
# FORMAT — one object per line:
#     canonical
#     canonical: synonym1, synonym2, ...
# The canonical name and every synonym are given to the detector as class prompts (so it can
# fire on whichever surface form it recognises), but they all COLLAPSE to the canonical for
# matching. This is CHAIR's synonym map (Rohrbach et al. 2018): it stops "cart" vs "trolley" or
# "fridge" vs "refrigerator" from being counted as hallucinations, while genuinely different
# objects (cucumber vs bell pepper) stay distinct — those are the errors we want to catch.
#
# Group only TRUE synonyms of the same physical object. Do NOT group visually-similar-but-
# different objects (cucumber / zucchini, onion / potato): confusing those is a real caption
# error and must remain detectable. To evaluate a different domain, copy this file and pass
# --vocab-file; do not edit the detector code. '#' comments and blank lines are ignored.
